This repo includes 4 branches with the aim of practicing using ThreeJS with VueJS as front-end framework.
The 4 branches:
  - Main: A playground where user can use WASD to control movement of the 3D model and do a walk around a gallery. User can walk in to the circle and toggle "Spacebar" to enter/exit floating mode
  - mapgen: A top-down view map with generated blocks representing buildings. Can use mouse to drag and hover.
  - mapgl: Based on MapGL, importing interactable 3D models with nodes representing points on map (Similar to Google Map). This require GPU to render smoothly.
  - testing : Just testing
